# Emoji assets

`girl.png` and `zombie.png` are from the
[jdecked/twemoji](https://github.com/jdecked/twemoji) project. Twemoji graphics
are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The PNGs are kept locally so Matplotlib can render the player markers reliably
without depending on platform emoji fonts or network access at runtime.
